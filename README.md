# Tim 11 - Sustav za upravljanje knjižnicom

Projektni zadatak iz kolegija **Baze podataka 1**.

Tema projekta je sustav za upravljanje knjižnicom (modeliranje baze podataka,
izrada sheme, punjenje podacima te izrada pogleda i upita).
